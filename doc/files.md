Filename            | Description
--------------------|----------------------------------------------------------------------------------------------------------------------------
banlist.dat         | stores the IPs/Subnets of banned nodes
kristatech.conf           | contains configuration settings for kristatechd or kristatech-qt
kristatechd.pid           | stores the process id of kristatechd while running
blocks/blk000??.dat | block data (custom, 128 MiB per file); since 0.8.0
blocks/rev000??.dat | block undo data (custom); since 0.8.0 (format changed since pre-0.8)
blocks/index/*      | block index (LevelDB); since 0.8.0
chainstate/*        | blockchain state database (LevelDB); since 0.8.0
evodb/*             | deterministic KTDIP3 masternode & special-tx state database (LevelDB); tracks CDeterministicMNManager & CCoinsView diffs
database/*          | BDB database environment for wallet.dat directly inside $DATADIR
db.log              | wallet database log file inside $DATADIR
debug.log           | contains debug information and general logging generated by kristatechd or kristatech-qt
fee_estimates.dat   | stores statistics used to estimate minimum transaction fees and priorities required for confirmation; since 0.10.0
activemasternode.conf | contains aliases, operator ECDSA private keys, and optional BLS private keys (`alias privkey [bls_privkey_hex]`) for single-IP multi-masternode hot nodes (used with `masternode=1`)
masternode.conf     | contains configuration settings for remote masternodes (cold controller wallet)
mncache.dat         | legacy pre-KTDIP3 masternode list cache
mnpayments.dat      | legacy pre-KTDIP3 masternode payments cache
peers.dat           | peer IP address database (custom format); since 0.7.0
wallet.dat          | personal wallet (BDB) stored directly in $DATADIR with keys, BLS keys, and transactions
.cookie             | session RPC authentication cookie (written at start when cookie authentication is used, deleted on shutdown): since 0.12.0
onion_private_key   | cached Tor hidden service private key for `-listenonion`: since 0.12.0
chainstate/* (keys) | includes UTXO set plus persistent ADAM registration cache (`adamregcache_v2`) and PoBLS key pins (`PinBLSPubKey`)
